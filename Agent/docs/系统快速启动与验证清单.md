### 阶段一：环境准备

**1. 硬件与系统要求**

- **操作系统**：Linux (Ubuntu 20.04+/CentOS 7+) 或 macOS
- **CPU/内存**：最低 4核 8G（推荐 8核 16G，运行本地 LLM 需要较多资源）
- **GPU**：推荐 NVIDIA 显卡（显存 ≥ 8G），用于 Ollama 加速；无 GPU 也可运行（仅 CPU 模式，速度较慢）

**2. 软件依赖**

- Docker & Docker Compose (V2)
- Git
- Python 3.11+ & Node.js 20+（仅本地开发调试需要，纯 Docker 部署可免）

**3. 获取代码并准备目录**

```bash
git clone <你的仓库地址> fiber-maintenance-agent
cd fiber-maintenance-agent

# 创建运行时数据目录
mkdir -p data/{chroma,memory.db,kb_pending,fiber_reports}
```

**4. 配置环境变量（可选）**

```bash
# 如需自定义后端地址或 LLM 地址，修改 config.yaml 或设置环境变量
export FIBER_BACKEND_URL=http://your-fiber-backend:8080
export OLLAMA_BASE_URL=http://ollama:11434
```

---

### 阶段二：一键部署

**1. 构建并启动全栈服务**

```bash
make up
# 或者手动执行：docker compose up -d --build
```

**2. 检查服务状态**

```bash
docker compose ps
```

*验证标准*：所有服务状态均为 `Up`，无 `Restarting`。

**3. 拉取并初始化 LLM 模型**

```bash
# 首次启动需拉取 qwen 模型（约 4-8GB）
docker compose exec ollama ollama pull qwen2.5:7b
# 重启 Agent 服务以加载模型
docker compose restart deerflow
```

---

### 阶段三：自动化测试

**1. 运行后端 API 与 Agent 单元测试**

```bash
make test
# 或者手动执行：docker compose exec deerflow python -m pytest tests/ -v
```

*验证标准*：测试通过率 100%，无 `FAILED` 或 `ERROR`。

**2. 运行全量接口自测并生成报告**

```bash
docker compose exec deerflow python tests/test_client.py --all --report
```

*验证标准*：控制台输出 `总计: X | 通过: X | 失败: 0`，并在 `tests/reports/` 下生成 JSON 报告。

### 阶段四：功能验证（人工验收）

**1. 统计面板验证**

- 访问：`http://localhost:5173/`
- 验证项：
  - 概览卡片（红/黄/告警数）正常显示
  - WS 状态标签显示为绿色“已连接”
  - 趋势图（ECharts）正常渲染

**2. 智能对话验证**

- 访问：`http://localhost:5173/chat`
- 验证项：
  - 输入“分析光纤 F1001 的衰耗”，验证 SSE 流式输出与 Markdown 渲染
  - 输入“当前有哪些红色告警”，验证 Sub-Agent 调度与工具调用
  - 故意断网/停掉后端，输入查询，验证友好降级提示

**3. 知识库管理验证**

- 访问：`http://localhost:5173/admin/knowledge`
- 验证项：
  - 上传 `.md` 文件，状态为 `PENDING`
  - 点击“通过” → 点击“入库”，状态变为 `ACTIVE`
  - 在检索测试框输入关键词，验证 RAG 混合检索返回相关文档

**4. 监控面板验证**

- 访问：`http://localhost:3001/`（Grafana，默认 admin/admin）
- 验证项：
  - Agent 性能概览面板有数据
  - QPS、LLM Token 消耗、后端存活指标正常采集

### 常见问题排查

| 现象                       | 排查命令/操作                                                                     |
| -------------------------- | --------------------------------------------------------------------------------- |
| Ollama 拉模型超时          | `docker compose exec ollama ollama list` 检查；检查网络或换国内镜像             |
| Agent 启动报 ChromaDB 错误 | 删除`data/chroma/` 目录后重启：`rm -rf data/chroma && make up`                |
| 前端 WS 一直显示断开       | 检查`frontend/nginx.conf` 中 proxy_pass 地址是否与 docker-compose 服务名一致    |
| 测试报告找不到             | 确认执行`test_client.py` 时加了 `--report` 参数，查看 `tests/reports/` 目录 |
