
# 紧急告警处理流程

## 响应流程（P0/P1）

### 第一阶段：确认（≤5min）

1. 确认告警真实性（排除采集误报）
2. 确认影响范围（单纤/多纤/整缆）
3. 确认业务影响（是否承载生产业务）

### 第二阶段：定位（≤10min）

1. 查看同网元对其他连纤状态
2. 检查近期施工/变更记录
3. 分析性能趋势（是否渐变/突变）
4. 判断故障类型：
   - 突变 → 光纤断裂/连接器脱落
   - 渐变 → 光纤老化/弯折/污染

### 第三阶段：处理

1. 通知相关方（业务方/施工方）
2. 启动抢修流程（如需现场处理）
3. 持续监控恢复情况

### 第四阶段：闭环

1. 确认告警清除、颜色恢复绿色
2. 记录故障案例
3. 更新知识库

## 注意事项

- 紧急告警 15min 内必须有人响应
- 无法远程恢复时立即启动现场抢修
- 同网元对 ≥3 条红色 → 疑似光缆中断，启动应急预案
