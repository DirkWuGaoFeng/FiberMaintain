
# 告警升级规则

## 自动升级条件

| 条件                         | 动作                   |
| ---------------------------- | ---------------------- |
| 次要告警持续 > 24h           | 升级为紧急             |
| 同一光纤 24h 内 ≥ 3 次告警  | 升级为紧急             |
| 同网元对 ≥ 3 条连纤同时红色 | 升级为紧急（光缆故障） |
| 恶劣天气 + 任何告警          | 升级一级               |
| 重要业务链路 + 任何告警      | 升级一级               |

## 人工升级

- 运维人员可手动升级任何告警
- 升级后自动触发通知

## 降级条件

- 告警清除 + 性能恢复正常 + 持续 30min → 自动降级/清除
- 人工确认误报 → 立即清除

## 通知规则

- 紧急告警：即时通知（企业微信 + 邮件）
- 次要告警：30min 汇总邮件
- 升级事件：即时通知
