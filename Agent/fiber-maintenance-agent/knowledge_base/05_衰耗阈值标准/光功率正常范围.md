# 光功率正常范围参考

## 有源盘光功率

| 盘类型    | 发送功率范围  | 接收灵敏度 | 过载点 |
| --------- | ------------- | ---------- | ------ |
| OTU 10G   | -1 ~ +2 dBm   | -24 dBm    | -3 dBm |
| OTU 100G  | +1 ~ +5 dBm   | -18 dBm    | +2 dBm |
| EDFA 功放 | +15 ~ +23 dBm | —         | —     |

## 无源盘光功率

| 盘类型     | 插入损耗 | 端口数 |
| ---------- | -------- | ------ |
| ODF 配线盘 | ≤0.5 dB | 3      |
| 分光器 1:2 | ≤3.5 dB | 3      |
| 分光器 1:4 | ≤7.0 dB | —     |

## 异常判定

- OOP 突降 > 3 dB：疑似激光器老化或光纤弯折
- IOP 突降 > 5 dB：疑似光纤断裂或连接器污染
- OOP 正常但 IOP 异常：问题在传输链路
- OOP 异常但 IOP 正常：问题在发送端
