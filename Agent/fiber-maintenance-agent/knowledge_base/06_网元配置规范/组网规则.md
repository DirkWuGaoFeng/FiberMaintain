
# 组网规则

## 基本拓扑

| 拓扑类型 | 描述       | 适用场景         |
| -------- | ---------- | ---------------- |
| 点对点   | 两网元直连 | 短距离专线       |
| 链型     | 多网元串联 | 沿线覆盖         |
| 环型     | 首尾相连   | 城域核心（保护） |
| 星型     | 中心辐射   | 汇聚层           |
| 网状     | 多路径互联 | 骨干网           |

## 连纤规则

1. 每条连纤连接两个不同网元的单盘端口
2. 同一网元对之间可有多条连纤（不同单盘/端口）
3. 连纤方向：源端（发送）→ 宿端（接收）
4. 保护组：主用 + 备用连纤

## 网元间连纤标识

- fiber_id: 全局唯一 int32
- 源端: src_board_id + src_port_id + src_ne_id
- 宿端: dst_board_id + dst_port_id + dst_ne_id

## 容量规划

- 单网元最大连纤数：取决于单盘槽位
- 系统支持 10 万条连纤
- 单次批量查询上限 100 条
