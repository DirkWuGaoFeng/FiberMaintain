
# 故障案例 001: 施工挖断光缆导致多纤中断

## 基本信息

- 时间: 2026-03-15 14:23
- 影响: NE101 ↔ NE205 之间 8 条连纤
- 持续: 4h 32min
- 级别: P0

## 现象描述

- 14:23 突然 8 条连纤同时变红
- 所有连纤 IOP 降至 -40 dBm（无光）
- OOP 正常（发送端未受影响）
- 触发紧急告警 × 8

## 根因分析

- 市政施工挖断 NE101→NE205 段光缆
- 物理断裂，非设备故障
- 同缆 8 芯全部中断

## 处理过程

1. 14:23 系统告警，值班员确认
2. 14:28 判断同缆故障（多纤同时中断）
3. 14:35 通知抢修队 + 业务方
4. 15:10 抢修队到达，OTDR 定位断点（距 NE101 3.2km）
5. 16:45 完成熔接
6. 17:02 验证恢复，告警清除
7. 18:55 全部连纤恢复绿色

## 经验总结

- 同网元对多纤同时红色 → 高度怀疑光缆故障
- OOP 正常 + IOP 无光 → 传输链路问题
- 突变（非渐变）→ 物理断裂概率大
- 市政施工高发期需加强巡检
