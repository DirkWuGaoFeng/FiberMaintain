
# 无源盘技术规格

## 概述

无源盘无需供电，完成光纤配线、分光、合波等物理连接功能。

## 常见类型

| 盘类型     | 功能          | 端口数   | 插入损耗 |
| ---------- | ------------- | -------- | -------- |
| ODF 配线盘 | 光纤终接/配线 | 3        | ≤0.5 dB |
| 分光器     | 光功率分配    | 3（1:2） | ≤3.5 dB |
| WDM 合波器 | 波分复用      | 多       | ≤1.0 dB |
| 光衰减器   | 功率调节      | 2        | 可调     |

## 端口约束

- 无源盘标准 3 端口设计
- 端口 1：公共端（COM）
- 端口 2/3：分支端
- 分光比：50:50（标准）/ 可定制

## 维护要点

- 定期检查连接器清洁度
- 插入损耗增大 → 清洁或更换
- 无需供电检查
