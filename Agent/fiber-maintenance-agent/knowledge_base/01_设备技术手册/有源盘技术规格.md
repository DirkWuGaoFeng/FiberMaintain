
# 有源盘技术规格

## 概述

有源盘是需要供电的光纤设备单盘，完成光电转换、信号放大、波长转换等功能。

## 常见类型

| 盘类型           | 功能     | 端口数      | 供电 |
| ---------------- | -------- | ----------- | ---- |
| OTU（光转发盘）  | 波长转换 | 2（IN/OUT） | 是   |
| EDFA（光放大盘） | 信号放大 | 2（IN/OUT） | 是   |
| OLP（光保护盘）  | 主备切换 | 4           | 是   |
| OSC（光监控盘）  | 监控通道 | 2           | 是   |

## 光功率指标

| 盘类型   | 发送功率    | 接收灵敏度 | 过载点 |
| -------- | ----------- | ---------- | ------ |
| OTU 10G  | -1~+2 dBm   | -24 dBm    | -3 dBm |
| OTU 100G | +1~+5 dBm   | -18 dBm    | +2 dBm |
| EDFA     | +15~+23 dBm | -30 dBm    | —     |

## 维护要点

- 定期检查风扇/温度
- 监控发送功率趋势（老化预警）
- 接收功率低于灵敏度 → 告警
