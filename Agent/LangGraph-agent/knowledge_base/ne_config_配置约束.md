
# 配置约束

## 单盘约束

- 有源盘：需供电，有源光模块
- 无源盘：无需供电，3 端口标准设计
- 单盘类型决定端口数量和速率

## 端口约束

- 发送端口 → 接收端口（不可同向）
- 单模 ↔ 单模（不可混接多模）
- 波长匹配（1310nm ↔ 1310nm）
- 速率匹配（10G ↔ 10G）

## 连纤约束

- 必须跨网元（src_ne_id ≠ dst_ne_id）
- 网元内连纤不纳入维护系统
- 一条连纤仅连接一个源端口和一个宿端口
- 保护组连纤需成对配置

## 性能采集约束

- 采集周期：5 分钟
- 数据保留：7 天（趋势）/ 30 天（统计）
- 单次查询最大 100 条连纤
- FIFO 排队处理批量请求
