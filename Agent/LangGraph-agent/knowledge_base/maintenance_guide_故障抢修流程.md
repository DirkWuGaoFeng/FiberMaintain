
# 故障抢修流程

## 抢修启动条件

- 红色告警 + 业务中断
- 同网元对 ≥ 3 条连纤同时红色
- 上级指令

## 抢修流程

### 1. 接报（≤5min）

- 确认故障信息
- 通知抢修队伍
- 准备工具仪表

### 2. 出发（≤15min）

- 携带 OTDR、光功率计、熔接机
- 携带备用光纤/跳线
- 携带图纸资料

### 3. 现场处理

- OTDR 定位故障点
- 判断故障类型（断裂/弯折/连接器）
- 实施修复（熔接/更换/清洁）
- 验证恢复（光功率测试）

### 4. 恢复确认

- 后端确认告警清除
- 颜色恢复绿色
- 性能指标正常
- 持续观察 30min

### 5. 闭环

- 填写抢修记录
- 录入故障案例库
- 更新知识库

## 时限要求

- 城区：≤2h 到达现场
- 郊区：≤4h 到达现场
- 抢修总时限：≤8h（特殊除外）
