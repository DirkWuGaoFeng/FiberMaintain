
# 端口规格与约束

## 光纤连接器类型

| 类型 | 特点         | 适用场景 |
| ---- | ------------ | -------- |
| LC   | 小型化，双工 | 设备端口 |
| SC   | 标准方形     | ODF 配线 |
| FC   | 螺纹固定     | 仪表测试 |
| MPO  | 多芯并行     | 高密度   |

## 端口约束规则

1. 同类型端口才能互连
2. 单模/多模不可混接
3. 波长必须匹配
4. 发送端 → 接收端（不可同向对接）

## 网元间连纤约束

- 必须跨网元（src_ne_id ≠ dst_ne_id）
- 网元内连纤不纳入光纤维护系统管理
- 一条连纤 = 源单盘端口 → 宿单盘端口
