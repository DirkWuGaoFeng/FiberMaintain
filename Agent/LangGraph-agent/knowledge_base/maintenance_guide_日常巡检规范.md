
# 日常巡检规范

## 巡检类型

| 类型     | 周期 | 内容                             | 负责人     |
| -------- | ---- | -------------------------------- | ---------- |
| 日常巡检 | 每日 | 红/黄统计，紧急告警处理          | 值班员     |
| 周期巡检 | 每周 | 全量性能检查，趋势分析           | 运维工程师 |
| 深度巡检 | 每月 | 历史分析，阈值评估，容量规划     | 高级工程师 |
| 专项巡检 | 按需 | 施工前后、恶劣天气后、重大保障前 | 专项小组   |

## 日常巡检流程

1. 查看实时统计（红/黄数量）
2. 处理所有紧急告警（P0/P1）
3. 检查黄色连纤趋势（是否恶化）
4. 记录异常情况
5. 生成日报

## 周期巡检流程

1. 全量连纤性能采集
2. 趋势分析（7 天对比）
3. 异常光纤清单
4. 维护建议
5. 生成周报

## 巡检记录要求

- 每次巡检必须记录时间、人员、结果
- 异常必须跟踪闭环
- 巡检报告存档 ≥ 1 年
