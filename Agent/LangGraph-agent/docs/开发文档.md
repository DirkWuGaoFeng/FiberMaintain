# 光纤维护服务 Agent v7.1-Final 开发文档

## 1. 项目概述

基于 LangGraph + LangChain 架构的光纤维护智能体，实现从用户自然语言输入到结构化诊断输出的全流程自动化。

**核心特性：**
- L0 规则引擎（25 条正则规则，< 10ms 响应）
- 三级 LLM 梯度（qwen2.5:14b / 7b / 3b）
- Narrator 校验回环 [v7.1 核心]（程序化校验 LLM 输出）
- 四重终止保障（轮次上限 / LLM 预算 / 无进展检测 / Tool 全失败熔断）
- 五级降级链（L0 正常 → L4 离线）
- 事件驱动主动诊断

## 3. 架构设计

### 3.1 主图编排（18 节点）

```
START → input_guard → rule_engine → [三路分流]
  ├─ fast_path → fast_path_executor → result_aggregator → END
  ├─ rule_hit_complex → param_gate → [params_ok / need_clarification]
  │   ├─ params_ok → intent_router → [五路分发]
  │   └─ need_clarification → clarification → rule_engine (回环)
  └─ rule_miss → intent_classifier → param_gate → ...

intent_router 五路分发:
  ├─ data_query → data_collector → rule_judgment → analysis_expert
  ├─ batch_query → batch_dispatcher → result_aggregator
  ├─ knowledge_qa → knowledge_qa → result_aggregator
  ├─ report → data_collector → ... → report_generator → report_evaluator
  └─ chitchat → result_aggregator

Controlled Loop (analysis_expert):
  ├─ need_more_data → data_collector (回环, ≤3次)
  ├─ direct_narrate → narrator → narrator_validator
  │   ├─ pass → result_aggregator
  │   └─ fail → template_fallback → result_aggregator
  ├─ generate_report → report_generator → report_evaluator
  │   ├─ pass → result_aggregator
  │   └─ refine → report_generator (≤1次)
  └─ degraded → degradation_handler → result_aggregator
```

### 3.2 四重终止保障

| 保障机制 | 阈值 | 触发动作 |
|---------|------|---------|
| 轮次上限 | ≤3 | 强制退出循环 |
| LLM 预算 | ≤10 次 | 强制退出循环 |
| 无进展检测 | 连续 2 次相同签名 | 强制退出循环 |
| Tool 全失败 | 所有 Tool 报错 | 进入降级 |

### 3.3 五级降级链

| 级别 | 条件 | 能力 |
|-----|------|------|
| L0 | 全部正常 | 14b 全功能 |
| L1 | 14b 不可用 | 7b 接管 |
| L2 | 7b 不可用 | 3b 最小推理 |
| L3 | 所有 LLM 不可用 | 纯模板/规则 |
| L4 | LLM + 后端均不可用 | 离线缓存 |

## 7. 关键设计决策

1. **判断/表述分离**：RuleJudgment（程序化）→ Narrator（LLM翻译）→ Validator（程序化校验），确保数据准确性
2. **Fast Path 零 LLM**：简单查询直接规则匹配 + Tool 调用 + 模板渲染，< 1s 响应
3. **参数三层防线**：Layer 1 提取 → Layer 2 ParamGate 校验 → Layer 3 Tool 断言
4. **事件驱动**：WebSocket 监听后端事件，CRITICAL 告警自动触发主动诊断
5. **本地优先**：SQLite Checkpointer + asyncio.Queue + JSONL 审计，无需 Redis/PostgreSQL
