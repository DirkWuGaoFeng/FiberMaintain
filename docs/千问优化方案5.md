### 2.2 同步机制矩阵

```
┌──────────────────────────┬──────────────────────────┬──────────────────────────┐
│      通信路径            │       同步机制           │       说明               │
├──────────────────────────┼──────────────────────────┼──────────────────────────┤
│ Stream → EventQueue      │ mutex + cond_var         │ 有界队列，背压           │
│ EventQueue → 处理线程    │ cond_var (100ms超时)     │ 批量drain               │
│ 处理线程 → 输出线程      │ SPSC无锁环形队列         │ 单生产者单消费者         │
│ 处理线程内部             │ 无锁                     │ 所有缓存仅该线程写       │
│ gRPC线程 → 缓存(读)     │ shared_mutex 读锁        │ 读写分离                 │
│ timer线程 → 缓存(读)    │ shared_mutex 读锁        │ 趋势采集只读             │
│ 处理线程 → 缓存(写)     │ shared_mutex 写锁(极短)  │ 仅在批量更新时短暂持有   │
└──────────────────────────┴──────────────────────────┴──────────────────────────┘
```

### 3.2 缓存创建与维护时机

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                       缓存生命周期                                              │
│                                                                                 │
│  ═══════════════ 服务启动 ═══════════════                                       │
│                                                                                 │
│  fiber_by_id_ / fiber_by_port_:                                                 │
│    TopologyService.BatchGetFibers() → 全量加载 → 写入缓存                       │
│                                                                                 │
│  alarm_cache_:                                                                  │
│    AlarmService.CreatePullCall() → 异步轮询 GetPullCallResult()                 │
│    → 全量写入（详见第4章 Pull 模式）                                            │
│                                                                                 │
│  port_dependency_index_:                                                        │
│    遍历 fiber_by_id_ 中所有网元间连纤 → DependencyBuilder.build_all()           │
│                                                                                 │
│  color_contexts_:                                                               │
│    遍历所有网元间连纤 → FiberTopologyResolver.resolve() → 初始化上下文          │
│                                                                                 │
│  color_by_fiber_:                                                               │
│    DB: SELECT fiber_id, color, scene_type FROM fiber_colors WHERE color IN (2,3)│
│    → 写入缓存（仅红/黄）                                                        │
│                                                                                 │
│  ═══════════════ 运行中 — 告警事件 ═══════════════                              │
│                                                                                 │
│  alarm_cache_:                                                                  │
│    ALARM_RAISED  → alarm_cache_[{b,p,l}] = {raised_at}  (写入/覆盖)            │
│    ALARM_CLEARED → alarm_cache_.erase({b,p,l})           (删除)                 │
│                                                                                 │
│  color_contexts_ / color_by_fiber_:                                             │
│    颜色变化 → 更新 color_contexts_ → 推入 change_queue                          │
│    → output_thread_ 异步更新 color_by_fiber_ + DB                               │
│                                                                                 │

## 4. 告警全量同步（Pull 模式）

### 4.1 Pull 模式机制说明

> **核心设计**：`AlarmService.CreatePullCall` 是**拉模式（Pull）机制**。光纤维护服务向告警服务**创建一个拉取任务**，告警服务**异步准备数据**，光纤维护服务**轮询获取结果**。此设计防止告警数据量过大时导致服务启动超时。

### 4.2 Pull 模式交互时序图

```
FiberMaintService              AlarmService                    告警数据存储
(调用方)                       (服务方)                        (后端)
    │                              │                              │

    │──CreatePullCall()──────────→│                              │

### 4.3 Pull 模式状态机

```
                    ┌──────────────┐
                    │   IDLE       │
                    │  (初始状态)  │

│                                                                                 │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │  class FiberTopologyResolver                                            │    │
│  │  {                                                                      │    │
│  │  public:                                                                │    │
│  │      // 构造: 注入 Layer 0 缓存引用                                    │    │
│  │      FiberTopologyResolver(                                             │    │

│  │          const vector<int32_t>& fiber_ids) const;                       │    │
│  │                                                                         │    │
│  │  private:                                                               │    │
│  │      // 判断宿端板卡类型                                                │    │
│  │      BoardType get_board_type(int32_t board_id) const;                  │    │
│  │                                                                         │    │
│  │      // 查找无源盘Port-2/Port-3上的网元内连纤对端                       │    │
│  │      optional<PeerInfo> find_peer_on_port(                              │    │
│  │          int32_t passive_board_id, int32_t port_id) const;              │    │
│  │                                                                         │    │
│  │      // 判定场景和Case                                                  │    │
│  │      pair<int32_t,int32_t> classify_scenario(                           │    │

│  │          const vector<PeerInfo>& peers) const;                          │    │
│  │  };                                                                     │    │

│                                                                                 │

│                                                                                 │
│  resolve(fiber_id)                                                              │
│    │                                                                            │

│    │     若不存在 → 返回 {is_valid=false}                                      │
│    │                                                                            │
│    ├─ 2. 判断 is_inter_ne                                                      │
│    │     若 false → 返回 {is_valid=false} (网元内连纤不计算颜色)               │
│    │                                                                            │
│    ├─ 3. 获取宿端板卡类型 get_board_type(dst_board_id)                         │
│    │     ├─ ACTIVE → scene_type=1, scenario_case=0                             │
│    │     └─ PASSIVE → scene_type=2, 继续判断Case                               │
│    │                                                                            │
│    ├─ 4. (场景2) 查找Port-2对端                                                │
│    │     find_peer_on_port(dst_board_id, 2)                                    │
│    │     ├─ 找到 → peer_B = {board_id, port_id, via_port=2}                   │
│    │     └─ 未找到 → peer_B = nullopt                                         │
│    │                                                                            │
│    ├─ 5. (场景2) 查找Port-3对端                                                │
│    │     find_peer_on_port(dst_board_id, 3)                                    │
│    │     ├─ 找到 → peer_A2 = {board_id, port_id, via_port=3}                  │
│    │     └─ 未找到 → peer_A2 = nullopt                                        │
│    │                                                                            │
│    ├─ 6. 判定Case                                                              │
│    │     ├─ peer_B && peer_A2 → Case A (双路保护)                              │
│    │     ├─ peer_B && !peer_A2 → Case B (单路)                                 │
│    │     └─ !peer_B → Case C (无保护)                                          │
│    │                                                                            │
│    └─ 7. 组装 FiberTopologyInfo 返回                                           │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘
```
