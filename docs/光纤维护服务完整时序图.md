## 告警消息处理流程图

### 整体处理流程

```mermaid
flowchart TD
    A[设备上报告警] --> B[AlarmService接收]
    B --> C[写入数据库]
    C --> D[发布AlarmEvent]
    D --> E[FiberMaintService接收事件]
    E --> F{事件类型}
  
    F -->|ALARM_RAISED| G[写入告警缓存]
    F -->|ALARM_CLEARED| H[删除告警缓存]
  
    G --> I[查找受影响连纤]
    H --> I
  
    I --> J[遍历affected_fibers]
    J --> K[入队颜色重算任务]
    K --> L[Worker线程处理]
  
    L --> M[读取连纤缓存]
    M --> N{场景判断}
  
    N -->|场景1| O[单跳寻路: 查询宿端告警]
    N -->|场景2| P[两跳寻路: 查询无源盘端口]
  
    O --> Q[计算颜色]
    P --> R[判断情况A/B/C]
    R --> Q
  
    Q --> S{颜色是否变化}
    S -->|是| T[更新数据库]
    S -->|否| U[结束]
  
    T --> V[更新颜色缓存]
    V --> W[推送颜色事件]
    W --> X[通知所有订阅客户端]
```

### 告警缓存处理流程

```mermaid
flowchart TD
    A[收到AlarmEvent] --> B{event_type判断}
  
    B -->|ALARM_RAISED| C[构造AlarmCacheKey]
    C --> D[构造AlarmCacheValue]
    D --> E[写入alarm_cache_]
    E --> F[记录日志]
  
    B -->|ALARM_CLEARED| G[构造AlarmCacheKey]
    G --> H[从alarm_cache_删除]
    H --> I[记录日志]
  
    F --> J[调用find_affected_fibers]
    I --> J
```

### 受影响连纤查找流程

```mermaid
flowchart TD
    A[find_affected_fibers<br/>board_id, port_id] --> B[遍历fiber_by_port_]
    B --> C{是否为网元间连纤}
  
    C -->|是| D{宿端board_id匹配}
    D -->|是| E[加入affected列表]
    D -->|否| F[继续遍历]
  
    C -->|否 网元内连纤| G{对端端口是Port-2或Port-3}
    G -->|是| H[查找无源盘Port-1关联的网元间连纤]
    H --> I{网元间连纤的宿端匹配无源盘}
    I -->|是| J[加入affected列表]
    I -->|否| F
    G -->|否| F
  
    F --> K{还有更多连纤}
    K -->|是| B
    K -->|否| L[返回affected列表]
```

### 颜色计算决策流程

```mermaid
flowchart TD
    A[calculate_color<br/>fiber_id] --> B[读取连纤缓存]
    B --> C{宿端是无源盘}
  
    C -->|否| D[场景1]
    D --> E[查询宿端端口告警]
    E --> F{has_critical}
    F -->|是| G[返回RED]
    F -->|否| H{has_minor}
    H -->|是| I[返回YELLOW]

    O --> P{Port-3有连纤}
  
    P -->|是| Q[情况A]
    Q --> R[查询board_B和board_A2告警]
    R --> S{双方都有CRITICAL}

    S -->|否| U{任一方有告警}

    U -->|否| W[返回GREEN]
  
    P -->|否| X[情况B]

    Z -->|否| AB{board_B有MINOR}
    AB -->|是| AC[返回YELLOW]
    AB -->|否| AD[返回GREEN]
```

### 颜色更新与事件推送流程

```mermaid
flowchart TD
    A[update_fiber_color] --> B[读取旧颜色]
    B --> C{颜色是否变化}
    C -->|否| D[返回]
  
    C -->|是| E[更新数据库fiber_colors]
    E --> F[写入fiber_color_changes]

    G -->|RED或YELLOW| H[写入/更新color_by_fiber_]

    L --> M{推送成功}
    M -->|是| N[继续下一个]
    M -->|否| O[移除失效订阅者]
  
    N --> P{还有订阅者}
    P -->|是| K
    P -->|否| Q[结束]
```

## 场景1：直连有源盘（网元间连纤）

### 场景1拓扑结构

```
┌── 网元 NE-A ──┐                    ┌── 网元 NE-B ──┐
│ [有源盘 A]   │    连纤 F001       │  [有源盘 B]   │
│  ne_id=100   │    (网元间)        │   ne_id=200   │
│  Port-1 ─────┼────────────────────┼─── Port-1     │
└───────────────┘                    └───────────────┘
```

### 1.1 服务启动初始化（异步模式）

```mermaid
sequenceDiagram
    participant FiberMaint as FiberMaintService
    participant AlarmService as AlarmService
    participant Topology as TopologyService
    participant DB as 数据库
    participant AlarmCache as 告警缓存
    participant FiberCache as 连纤缓存
    participant Worker as 颜色重算Worker

    FiberMaint->>Topology: BatchGetFibers()
    Topology-->>FiberMaint: 全量连纤列表
  
    FiberMaint->>FiberCache: 写入 fiber_by_id_ 和 fiber_by_port_

    FiberMaint->>AlarmService: CreatePullCall(include_history=false)
    AlarmService-->>FiberMaint: {task_id=T1, status=processing}

    AlarmService->>AlarmService: 异步查询数据库(新线程)
    AlarmService->>DB: SELECT * FROM current_alarms
    DB-->>AlarmService: 全量告警数据
    AlarmService->>AlarmService: 更新任务状态为completed

    FiberMaint->>AlarmService: GetPullCallResult(task_id=T1)
    AlarmService-->>FiberMaint: {status=completed, data=[alarm1, alarm2, ...]}
  
    FiberMaint->>AlarmCache: 逐条写入 alarm_cache_[{b,p,l}]
  
    FiberMaint->>FiberCache: 遍历所有网元间连纤
    loop 每个连纤
        FiberMaint->>Worker: enqueue_color_recalc(fiber_id)
        Worker->>AlarmCache: 查询告警状态
        Worker->>FiberCache: 查询连纤信息
        Worker->>DB: INSERT/UPDATE fiber_colors
    end
  
    FiberMaint->>AlarmService: SubscribeAlarmEvents()
    FiberMaint->>Topology: SubscribeFiberEvents()
```

**流程说明**：

1. **先同步连纤缓存**：FiberMaintService 首先调用 TopologyService 获取全量连纤信息，写入本地缓存
2. **异步拉取告警**：创建 PullCall 任务后立即返回，AlarmService 在后台线程中异步查询数据库
3. **轮询获取结果**：FiberMaintService 定期轮询 PullCall 结果，不阻塞主线程
4. **实时颜色重算**：获取告警数据后，逐条更新告警缓存并触发颜色重算任务，Worker 线程并行处理，不等待所有计算完成

### 1.2 宿端有源盘B产生告警

```mermaid
sequenceDiagram
    participant Device as 设备
    participant AlarmService as AlarmService
    participant FiberMaint as FiberMaintService
    participant AlarmCache as 告警缓存
    participant FiberCache as 连纤缓存
    participant Worker as 颜色重算Worker
    participant DB as 数据库

    Device->>AlarmService: ReportAlarm(board_id=B, port_id=1, level=CRITICAL)
    AlarmService->>DB: INSERT INTO current_alarms
    AlarmService->>FiberMaint: AlarmEvent(event_type=ALARM_RAISED, board_id=B, port_id=1)
  
    FiberMaint->>AlarmCache: 写入 alarm_cache_[{B,1,1}]
  
    FiberMaint->>FiberCache: find_affected_fibers(B, 1)
    Note over FiberCache: 第一跳: 直接找到网元间连纤F001<br/>B是dst(宿端) → 影响颜色
    FiberCache-->>FiberMaint: [F001]
  
    FiberMaint->>Worker: enqueue_color_recalc(F001)
  
    Worker->>FiberCache: recalculate_fiber_color(F001)
    FiberCache-->>Worker: F001信息(场景1:宿端有源盘B)
  
    Worker->>AlarmCache: get_port_alarm_summary(B, 1)
    AlarmCache-->>Worker: {has_critical=true, has_minor=false}
  
    Worker->>Worker: calculate_color() → RED
  
    Worker->>DB: UPDATE fiber_colors SET color=RED
    Worker->>DB: INSERT INTO fiber_color_changes(old=GREEN, new=RED)
  
    Worker->>ColorCache: 更新 color_by_fiber_[F001] = RED
    Worker->>ColorEvent: push_color_event(F001, GREEN→RED)
  
    loop 所有订阅客户端
        ColorEvent->>Client: FiberColorEvent(fiber_id=F001, old=GREEN, new=RED)
    end
```

### 1.3 宿端有源盘B清除告警

```mermaid
sequenceDiagram
```

### 2.3 删除宿端无源盘Port-3关联的连纤（情况A→情况B）

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Topology as TopologyService
    participant FiberMaint as FiberMaintService
    participant FiberCache as 连纤缓存
    participant Worker as 颜色重算Worker
    participant AlarmCache as 告警缓存
    participant DB as 数据库

    Client->>Topology: DeleteFiber(fiber_id=F003)  // A2.Port-1 ↔ D.Port-3
    Topology->>DB: DELETE FROM fiber_connections WHERE fiber_id=F003
    Topology->>FiberMaint: FiberEvent(event_type=FIBER_DELETED, fiber_id=F003)
  
    FiberMaint->>FiberCache: 读取F003信息(网元内连纤)
    FiberCache-->>FiberMaint: {src=A2, dst=D, dst_port=3, is_inter_ne=false}
  
    FiberMaint->>FiberCache: 删除F003缓存
  
    Note over FiberMaint,FiberCache: 识别: 无源盘D的Port-3被释放
    FiberMaint->>FiberCache: 查找D.Port-1关联的网元间连纤
    FiberCache-->>FiberMaint: [F001]
  
    FiberMaint->>Worker: enqueue_color_recalc(F001)
  
    Worker->>FiberCache: recalculate_fiber_color(F001)
    FiberCache-->>Worker: 场景变更: 情况A → 情况B
```
