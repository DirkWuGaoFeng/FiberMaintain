## 一、C++ 后端改动（Services）

### Phase 1：核心架构重构（新增 14 文件 + 修改 2 文件）

|------|------|------|

| `fiber_maint_service/fiber_topology_resolver.h/.cpp` | 新增 | Layer 1 拓扑解析器：resolve/resolve_batch/classify_board/find_peers_on_passive_board |
| `fiber_maint_service/target_builders.h/.cpp` | 新增 | Layer 2 目标构建器：AlarmTargetBuilder, PerfTargetBuilder, SpanlossTargetBuilder（含 batch 去重） |
| `fiber_maint_service/color_strategy.h/.cpp` | 新增 | Layer 3 颜色策略体系：IColorStrategy 接口 + Scene1/2CaseA/2CaseB/2CaseC + ScenarioRegistry |
| `fiber_maint_service/perf_executor.h/.cpp` | 新增 | Layer 3 性能查询执行器：单查/批量去重单次 RPC |
| `fiber_maint_service/spanloss_calculator.h/.cpp` | 新增 | Layer 3 衰耗计算器：OOP-IOP 计算 + 批量 |
| `fiber_maint_service/event_queue.h` | 新增 | CoalescingEventQueue：alarm HashMap 同 key 覆盖（减少~80%）+ fiber FIFO 有序 |

| `fiber_maint_service/fiber_maint_service_impl.cpp` | 修改 | 重写 calculate_color() 委托策略；find_affected_fibers() O(1) 索引；所有 gRPC 查询使用 shared_lock |

### Phase 2：高级特性（新增 5 文件 + 修改 2 文件）
