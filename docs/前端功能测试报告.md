   ```javascript
   function updateNEPairs(scenes, colorLookup) {
     const pairMap = {}
     scenes.forEach(s => {
       if (!s || !s.found || !s.scene) return
       const fiber = s.scene.inter_ne_fiber
       const key = [a, b].sort().join('-')
       if (!pairMap[key]) pairMap[key] = { a, b, red: 0, yellow: 0 }
       const color = colorLookup[fiber.fiber_id] || 'g'
       if (color === 'r') pairMap[key].red++
       else if (color === 'y') pairMap[key].yellow++
     })
     pairs.value = Object.values(pairMap)
   }
   ```

## 3. 自然语言处理流程

### 3.1 完整流程链路

```
用户输入 → 前端(MainView.vue) → Python Agent(/api/v1/chat) → Lead Agent → LLM → 
工具调用 → 子智能体 → 后端API → 返回结果 → 流式输出 → 前端渲染
```

### 3.3 Lead Agent核心逻辑

- 当网元间连纤端点为无源盘时，有源盘通过网元内连纤连接
- 遍历`ne_internal_fibers`，检查不在`passive_board_ids`中的单盘
- 查询其类型，若为ACTIVE则按NE归属设置`src_active_board`/`dst_active_board`

**场景API验证（Fiber 77）：**
```json

  "dst_active_board": {"board_id": 50091, "ne_id": 409, "board_type": 1},
```
